Royal Red Chilli — Data Analytics Project
Project Overview
This project analyzes the sales, purchases, payments, customers, and inventory of Royal Red Chilli, a dry red chilli and chilli powder business.
Tools Used
	• MySQL — Data storage and SQL analysis
	• Power BI — Interactive dashboard and data visualization
	• Microsoft Excel — Data review and reporting
Business Questions
	• What are the total sales and gross profit?
	• How much payment has been received?
	• What is the outstanding payment amount?
	• How much stock is currently available?
	• Which products and customers contribute to sales?
Dashboard Highlights
	• Total Sales
	• Gross Profit
	• Payments Received
	• Outstanding Amount
	• Current Stock
	• Current Stock Value
	• Monthly Sales
	• Product-wise Sales
	• Customer-wise Sales
Project Files
	• SQL/ — SQL analysis queries
	• PowerBI/ — Power BI dashboard file
	• Report/ — PDF project report
	• Screenshots/ — Dashboard screenshots
Project Objective
To use SQL and Power BI to analyze business data, monitor sales and inventory, and support better business decisions.
Note
The results represent the data available in the project database and may not represent actual business performance.
